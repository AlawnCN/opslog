## 更新内容

- 新增外观主题选择，共提供 14 种主题；OpsLog、Reader 与 Web 支持主题记忆，桌面主程序与 Reader 共享外观偏好，并优化启动恢复与多窗口同步。
- 统一主题下的下拉选择、弹窗、日志表格及快捷操作样式，改善明暗主题的文字对比度、键盘操作和减少动态效果体验。
- HTML 日志与 AI 分析报告导出时保留当前主题，离线打开也能呈现一致的外观。
- 优化结构化日志与 Java 对象的折叠交互：支持逐层展开、逐层折叠及全部展开/折叠，减少查看复杂嵌套日志时的操作成本。
- 增加 SSH 连接复用，减少连续查询、读取明细及分析时的重复握手与认证；Web 和桌面密码连接支持连接池，macOS 的系统 SSH/私钥连接支持 ControlMaster 复用。
- 完善 SSH 连接生命周期：环境切换、配置修改、空闲回收与退出时释放连接；保持主机指纹校验，失败命令不自动重放，取消后允许后续操作重新连接。
- 增加主题、结构折叠、SSH 连接池与原生 SSH 集成回归测试，并补充主题和连接复用说明。

## macOS 首次启动

当前版本未使用 Apple Developer ID 签名或公证。如果 macOS 阻止启动，将应用拖到“应用程序”后，在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/OpsLog.app
```

OpsLog Reader：

```bash
xattr -dr com.apple.quarantine "/Applications/OpsLog Reader.app"
```

然后重新打开；如仍受阻，请在“系统设置 → 隐私与安全性”允许打开。移除隔离属性不等于 Apple 签名或公证。
