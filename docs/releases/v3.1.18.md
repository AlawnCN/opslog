## 更新内容

- 新增 Local 本地日志源：在环境配置中添加本地应用目录，无需 SSH 服务器或外部脚本运行环境，即可查询交易汇总、应用日志并阅读交易明细。
- 支持多个应用独立配置解析规则，复用现有字段映射和 AI 辅助分析流程；支持中文、空格及各平台原生绝对路径。Web/LAN 模式读取服务端机器目录，而非访问者浏览器所在电脑。
- 本地分页会话冻结文件范围及长度，避免后续追加日志改变当前查询；支持多行记录、时间边界、条件过滤及查询取消，检测文件轮转或截断后提示重新查询。
- 交易明细按完整日志 ID 精确读取对应 TRC 文件；限制读取范围，发现文件时不跟随符号链接，并校验真实路径与文件身份。
- 完善 Local 环境配置、导入导出、日志源提示与操作入口，Local 配置不携带 SSH 服务器和认证参数；新增本地读取、解析、分页与路径边界回归测试。

## macOS 首次启动

当前版本未使用 Apple Developer ID 签名或公证。如果 macOS 阻止启动，将应用拖到“应用程序”后，在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/OpsLog.app
```

OpsLog Reader：

```bash
xattr -dr com.apple.quarantine "/Applications/OpsLog Reader.app"
```

然后重新打开；如仍受阻，请在“系统设置 → 隐私与安全性”允许打开。移除隔离属性不等于 Apple 签名或公证。
