## 更新内容

- 内置 SSH 密码认证，支持密码及交互式密码登录；首次连接可核对并保存服务器指纹，密钥变化时拒绝连接。
- 修复 Windows 检出脚本的换行兼容问题；macOS SSH 加密依赖采用静态构建，改善绿色版的可移植性。
- 优化 Trace 阅读器：支持关键字过滤并保留上层调用关系，可调整调用信息列宽，悬浮详情增加延迟与过渡效果。
- 优化文本全选快捷键，聚焦输入框或结构化日志编辑器时只选择当前区域；Reader 按 Escape 保留已打开的日志。
- 区分扫描范围受限与服务器执行失败，查询结果可直接提示覆盖范围；修复环境配置切换时的表单状态问题。
- 新增豆包、智谱 GLM、MiniMax、阿里 Qwen 的 AI 服务预设及配置提示。

## macOS 首次启动

当前版本未使用 Apple Developer ID 签名或公证。如果 macOS 阻止启动，将应用拖到“应用程序”后，在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/OpsLog.app
```

OpsLog Reader 请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/OpsLog Reader.app"
```

然后重新打开；如仍受阻，请在“系统设置 → 隐私与安全性”允许打开。移除隔离属性不等于 Apple 签名或公证。
