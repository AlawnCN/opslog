## 更新内容

- 修复 SSH 交易汇总解析：兼容有无前导竖线及两种毫秒分隔符，保留完整结果信息、Trace ID 和来源节点；同一日志 ID 的不同服务记录不再混合覆盖，同时间戳分页保持稳定。
- 优化汇总日志发现：支持应用根目录内的自定义相对路径与多层目录；新增按服务器选择最新汇总文件或读取全部匹配文件的策略，并阻止越界路径和软链接读取。
- 单笔明细按完整日志 ID 精确定位 TRC 文件，保留异步后缀；文件缺失时明确提示，不再用数据库或事件片段冒充明细，空明细禁止分析和导出。
- 增强 AI 日志配置：保留完整首尾样本，依据实际样本回放验证字段映射，拦截错位、漏配及事件混入；失败时保留诊断供核对。
- 优化环境配置：保存不再丢失解析规则和元数据，增加未保存草稿保护、错误定位、删除/恢复撤销、时区偏移提示及导入导出流程保护。
- 优化 SSH 首次连接指纹确认与重试交互；修改主机或端口后清除旧指纹，避免错误复用。
- 增加 Windows 完整构建的时间余量，并补充共享脚本、Web 和 Rust 回归测试。

## macOS 首次启动

当前版本未使用 Apple Developer ID 签名或公证。如果 macOS 阻止启动，将应用拖到“应用程序”后，在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/OpsLog.app
```

OpsLog Reader：

```bash
xattr -dr com.apple.quarantine "/Applications/OpsLog Reader.app"
```

然后重新打开；如仍受阻，请在“系统设置 → 隐私与安全性”允许打开。移除隔离属性不等于 Apple 签名或公证。
