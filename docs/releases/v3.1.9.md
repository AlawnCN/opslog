## 更新内容

- SSH 日志查询支持按应用配置日志源、字段解析及匹配规则；新增日志样本采集和 AI 辅助分析配置，便于接入不同格式的日志。
- 优化 SSH 查询的时间范围与扫描预算处理，保留多行日志和交易明细，并在结果不完整时明确提示。
- 新增查询终止操作，Web 与桌面端可取消正在执行的查询及 AI 分析，减少无效等待。
- 改进 OpsLog Reader 的打开文件反馈、窗口标题栏、窗口位置和尺寸记忆，以及版本检查入口。
- 统一 SSH 脚本的构建打包路径，并增加相关回归测试。

## 发布包

- OpsLog 与 OpsLog Reader：Windows x64 安装版和绿色版；macOS Apple Silicon（ARM64）与 Intel（x64）的 DMG、绿色版和自动更新包。

## macOS 首次启动

当前版本未使用 Apple Developer ID 签名或公证。如果 macOS 阻止启动，将应用拖到“应用程序”后，在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/OpsLog.app
```

OpsLog Reader 请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/OpsLog Reader.app"
```

然后重新打开；如仍受阻，请在“系统设置 → 隐私与安全性”允许打开。移除隔离属性不等于 Apple 签名或公证。
