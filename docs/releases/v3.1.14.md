## 更新内容

- 优化 SSH 声明式汇总查询：先过滤时间再解析其他字段，并复用字段正则，减少无关历史记录的解析开销。
- 新增适用汇总日志的快照游标分页，固定文件清单和完整记录边界；翻页增量续读、复用候选缓存，避免每页重复扫描。文件轮转、截断、会话过期及资源上限会明确提示重新查询，不静默替换数据源。
- 优化环境启动加载：列出环境不再等待所有 SSH 服务器，仅解析当前所选环境的时区，并在准备完成前阻止查询；保留手动配置的时区偏移。
- 环境配置新增“探测连接”：使用当前未保存的服务器草稿验证连接、认证、只读命令和时区，支持取消及主机指纹确认，不读取业务日志或自动保存配置。
- 修复主题内层背景与外框边角不一致的问题，兼容非对称圆角和直角主题；保留日期、字段菜单和焦点效果的显示边界。
- 补充 SSH 分页、查询会话、启动加载、连接探测及主题回归测试。快照分页仅适用于满足条件的声明式汇总规则；其他日志来源保留原有兼容查询流程。

## macOS 首次启动

当前版本未使用 Apple Developer ID 签名或公证。如果 macOS 阻止启动，将应用拖到“应用程序”后，在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/OpsLog.app
```

OpsLog Reader：

```bash
xattr -dr com.apple.quarantine "/Applications/OpsLog Reader.app"
```

然后重新打开；如仍受阻，请在“系统设置 → 隐私与安全性”允许打开。移除隔离属性不等于 Apple 签名或公证。
