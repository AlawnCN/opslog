## 更新内容

- 新增分类字体设置：界面、表格、代码和文档可独立调整字体与字号，支持系统已安装的自定义字体、实时预览及重置，并在下次启动时保留设置。OpsLog Reader 同步支持。
- 优化表格与调用链列宽操作：支持拖拽调整、双击按内容自适应及键盘操作，扩展列宽范围；分析报告中的 Markdown 表格也可调整列宽。
- 离线日志、Trace 快照及 AI 分析 HTML 导出保留字体设置，离线页面支持相应的列宽调整与自适应操作。
- 调整顶部工具栏布局，将环境与连接状态合并展示，统一外观设置入口、控件高度及窄窗口适配。
- SSH 环境初始化主动确认服务器连接，区分连接中、就绪与失败状态；首次主机密钥确认提前到初始化阶段，Web、桌面端及局域网共享接口保持一致。
- 补充字体设置、列宽计算、工具栏及 SSH 连接复用与部分失败场景的回归测试。

## macOS 首次启动

当前版本未使用 Apple Developer ID 签名或公证。如果 macOS 阻止启动，将应用拖到“应用程序”后，在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/OpsLog.app
```

OpsLog Reader：

```bash
xattr -dr com.apple.quarantine "/Applications/OpsLog Reader.app"
```

然后重新打开；如仍受阻，请在“系统设置 → 隐私与安全性”允许打开。移除隔离属性不等于 Apple 签名或公证。
