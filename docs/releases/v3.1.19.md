## 更新内容

- 新增 Trace 调用链离线 HTML 导出：保留完整链路、时间轴、当前主题及搜索/折叠状态，无需连接 OpsLog 即可离线阅读。
- 离线页面支持按调用名称、服务、SQL 和 Span ID 搜索，保留命中节点的父级路径，可展开 Span 详情及原始字段，并支持全部折叠/展开。
- 导出时显示处理中状态并防止重复操作；桌面端支持保存 Trace 快照，继续兼容原有离线日志文件。
- 新增导航栏折叠/展开与本机状态记忆，收起时保留页面入口和时区提示，为查询与阅读区域留出更多空间。
- 补充离线交互、主题保留、空链路及不可信内容转义的回归测试，并更新使用说明。

## macOS 首次启动

当前版本未使用 Apple Developer ID 签名或公证。如果 macOS 阻止启动，将应用拖到“应用程序”后，在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/OpsLog.app
```

OpsLog Reader：

```bash
xattr -dr com.apple.quarantine "/Applications/OpsLog Reader.app"
```

然后重新打开；如仍受阻，请在“系统设置 → 隐私与安全性”允许打开。移除隔离属性不等于 Apple 签名或公证。
