## 更新内容

- 优化 SSH 交易日志查询：交易列表只读取大文件末尾的有限片段；没有列表结果时，改为从交易汇总日志按时间范围检索，减少对大量明细文件的全量扫描。
- 为单笔日志和汇总日志设置读取预算，避免超大日志拖慢或中断查询；达到扫描上限时在查询结果中明确提示可能不完整。
- 改善 SSH 日志查询在多文件、多服务器环境下的响应与资源占用。

## 发布包

- OpsLog 与 OpsLog Reader：Windows x64 安装版和绿色版；macOS Apple Silicon（ARM64）与 Intel（x64）的 DMG、绿色版和自动更新包。

## macOS 首次启动

当前版本未使用 Apple Developer ID 签名或公证。请仅从本 Release 下载，并先参照 `SHA256SUMS` 校验完整性。将应用拖到“应用程序”后，如果 macOS 阻止启动，在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/OpsLog.app
```

OpsLog Reader 请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/OpsLog Reader.app"
```

然后重新打开；如仍受阻，请在“系统设置 → 隐私与安全性”允许打开。
