## 更新内容

- 优化 SSH 快照汇总的条件查询：完整字段解析前先做大小写不敏感的字面量 AND 预筛，减少日志 ID、流水号、交易码、节点及正文等选择性条件下的无效解析。
- 保留字段级精确验证、耗时与状态判断，避免仅在其他字段或 JSON 正文中出现的文本被误认为命中；不把查询条件解释成正则或拼接为 shell 命令。
- 保持时间边界、同毫秒记录组和游标续读语义；旧交易事件跨记录聚合不启用该预筛，避免遗漏聚合所需记录。
- 新增组合条件、Unicode、特殊字符、字段串位、异步 ID 后缀及连续分页的回归对照，并验证预筛前后返回字段、顺序和游标位置一致。

## macOS 首次启动

当前版本未使用 Apple Developer ID 签名或公证。如果 macOS 阻止启动，将应用拖到“应用程序”后，在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/OpsLog.app
```

OpsLog Reader：

```bash
xattr -dr com.apple.quarantine "/Applications/OpsLog Reader.app"
```

然后重新打开；如仍受阻，请在“系统设置 → 隐私与安全性”允许打开。移除隔离属性不等于 Apple 签名或公证。
